# Fluff

> 갤러리 속 최애 사진을 솜인형으로 만들고, 나만의 3D 방에서 함께 지내는 iOS 앱

SMVD 사용자경험디자인 II 프로젝트 · SwiftUI 워킹 프로토타입

[2026-11-10 성능 개선 및 실기기 측정 리포트](docs/performance-report-2026-11-10.md)

사진으로 만든 인형을 만지고, 방에 놓고, 함께 공부하거나 쉬어보세요. 현재 앱은 **솜뭉치들 · 내 방 · 마이** 세 개의 탭으로 구성되어 있습니다.

## 기획 배경

좋아하는 대상의 사진은 갤러리에 쌓이지만, 다시 보는 것 외에 즐길 방법은 많지 않습니다. Fluff는 실물 굿즈의 비용과 진열 공간 부담 없이, 사진을 직접 꾸미고 만질 수 있는 작은 동반자로 만드는 경험을 제안합니다.

- **주요 사용자**: 아이돌과 캐릭터를 좋아하고, 이동 중이나 잠들기 전 짧은 시간에 나만의 공간을 즐기고 싶은 대학생 팬
- **현재 범위**: 사진으로 인형 만들기, 개인 방 꾸미기, 인형과 함께 집중하고 쉬기
- **목표 지표**: 하루 인형 터치 20회 이상, 방 체류 3분 이상, 함께 집중한 시간. 지표 수집 기능은 아직 구현하지 않았습니다.

## 주요 기능

| 기능 | 현재 구현 |
| --- | --- |
| 인형 만들기 | 사진 선택 → 자동 배경 제거·지우기·복원 → 인형 모양·속재료·이름 → 제작 → 완성 |
| 프리셋 인형 | 토끼·곰·고양이 모양, 얼굴 사진 배치, 부위별 크기·높이·너비·위치·색상 조절 |
| 사진 모양 인형 | 배경을 지운 사진의 윤곽을 따라 두께가 있는 메시를 생성하고 사진을 입체 표면에 적용 |
| 인형과 놀기 | 누르기·쓰다듬기, 속재료별 햅틱·효과음, 춤추기, AR 촬영, 공유 |
| 내 방 | 3D 방에 인형 배치, 끌기·자리 탭으로 이동, 배치 취소·완료, 방에서 빼서 목록에 보관 |
| 방 꾸미기 | 가구·벽지·바닥재·러그·장식 선택, 가구 이동·90도 회전·좌우 반전, 되돌리기·다시하기 |
| 색상·사진 꾸미기 | 가구를 두 번 탭해 색상·사진 편집, 사진 채우기·맞추기·확대·이동·반전·회전, 창틀 색상 변경 |
| 함께 집중하기 | 공부·독서·과제 선택, 시간 설정 후 집중 시작, 집중·휴식 타이머, 일시정지, 날짜별·인형별 집중 시간 기록 |
| 함께 쉬기 | 가구를 피해 침대로 걸어가기, 잠들기, 일어나 원래 자리로 돌아오기, 여러 인형과 창밖 구경, 라디오·ASMR |
| 창밖 풍경 | 시간대별 하늘·해·달·별, 움직이는 구름과 새, 날씨에 따른 비·눈 연출 |

집중은 시간을 설정 화면에서 확정해야 시작할 수 있습니다. 잠든 인형을 깨우면 침대에서 내려와 이전 배치 위치로 돌아가며, 그 자리가 막혔으면 빈자리를 찾거나 안내를 표시합니다.

## 실행 방법

### 준비

- iOS 26.4 SDK를 지원하는 Xcode
- iOS 26.4 이상을 실행하는 iPhone 또는 시뮬레이터
- 앱 실행에 필요한 별도 패키지 설치는 없습니다.

### 실행

1. `Malrang.xcodeproj`를 엽니다.
2. 실기기에서 실행한다면 **Signing & Capabilities → Team**을 본인의 개발 계정으로 지정합니다.
3. 실행할 iPhone 또는 시뮬레이터를 선택하고 **Run**을 누릅니다.
4. 시작 화면에서 진입한 뒤 닉네임을 설정합니다. Apple·카카오 버튼은 현재 실제 인증과 연결되지 않은 로컬 프로토타입입니다.

자동 배경 제거와 AR 촬영은 실제 iPhone에서 확인해야 합니다. 시뮬레이터에서 배경 제거가 실패하면 **사진 그대로 쓰기**로 이어갈 수 있습니다.

## 데이터와 권한

- **사진 선택**: `PhotosPicker`로 사용자가 고른 사진만 가져오며, 전체 앨범 접근 권한을 요청하지 않습니다.
- **카메라**: AR 촬영에서 사용합니다. AR을 여는 동안 홈의 3D 장면을 내려 렌더링 충돌을 피합니다.
- **위치**: 창밖 구경에서 현재 날씨를 불러올 때 사용합니다. 허용하지 않아도 창밖 구경은 가능합니다.
- **날씨 조회**: 허용된 위치의 위도·경도를 소수점 두 자리로 반올림해 Open-Meteo에 전달합니다.
- **로컬 저장**: 인형·방·꾸미기 사진은 SwiftData, 집중 세션과 기록은 UserDefaults에 저장합니다.

현재 친구·방 방문·방명록·멀티 룸·SharePlay 기능은 포함하지 않습니다.

## 확인한 동작과 남은 검증

2026-11-03 작업 기준입니다. 자동 검사 결과와 시뮬레이터 확인을 구분해 기록합니다.

| 항목 | 확인 내용 |
| --- | --- |
| 앱 빌드 | iOS 시뮬레이터 Debug 빌드 성공 |
| 집중 세션 검사 | 시간 확정 전 시작 차단, 실행 중 설정 잠금, 일시정지·재개, 저장·복원, 날짜별·인형별 기록 검사 통과 |
| 침대 경로 검사 | 회전한 가구 회피, 침대 접근 방향, 접근 불가능한 배치 검사 통과 |
| 시뮬레이터 동작 | 집중 설정 후 타이머 시작, 침대에서 일어나 자리로 이동, 창문 영역 터치 확인 |

### 사용한 도구

- **Claude Code**: 초기 기획·규칙 정리와 SwiftUI·RealityKit 구현, 디버깅

- **Figma MCP**: 원본 프레임과 문구·치수·상태, 수정 요청 확인

### 효과가 있었던 작업 방식

1. **규칙을 먼저 기록하기**: 색상·간격·모서리, 금지 사항, 빈 화면·실패·권한 거부 상태를 문서로 고정했습니다.
2. **Figma 링크와 구현 범위를 함께 전달하기**: 원본 화면을 기준으로 작업하고, 임시 에셋이 필요한 부분을 명시했습니다.
3. **증상을 구체적으로 전달하기**: AR 화면이 비거나 권한 창이 뜨지 않는 상황을 실행 환경과 함께 확인했습니다.
4. **기능을 단계별로 검증하기**: 생성·배치·가구 동작을 나누어 구현하고, 실제 화면과 저장 결과를 확인했습니다.

<summary>가구·일러스트 에셋 관리</summary>

현재 홈과 가구 목록은 `CozyFurniture`의 3D 가구를 기준으로 사용합니다. 손그림 일러스트 생성 도구와 리소스도 저장소에 보관하고 있습니다.

- `scripts/room-illustration.svg`: Figma 방 일러스트 원본 벡터
- `scripts/prepare_furniture_illustration.py`: 원본에서 `RoomIllustration.json` 생성
- `scripts/render_illustration_textures.cjs`: 원본 SVG 질감 필터를 PNG로 렌더링
- `scripts/build_illustration_atlas.swift`: 일러스트 이미지 묶음·투명도 마스크·좌표 메타데이터 생성
- `scripts/render_design_a_assets.cjs`: 원본 SVG 질감을 보존한 UI 이미지 생성

### 가구 목록 이미지 갱신

Debug 실행 인자 `--export-furniture-thumbnails`로 홈과 같은 가구 모델을 렌더링합니다. 앱의 `Documents/FurnitureCatalog`에 생성된 `complete.txt`에서 11종 완료를 확인한 뒤, `Assets.xcassets/Furniture3D`의 같은 이름 PNG를 교체합니다. 이 작업은 사용자의 방이나 사진 데이터를 변경하지 않습니다.

### 배치 동작

- 인형은 길게 누르거나 바로 끌어서 옮기며, 선택한 인형을 놓을 자리를 탭할 수도 있습니다.
- 새 인형의 방 배치를 취소하면 목록에 보관합니다. 저장 실패 시 배치 모드를 유지하고 재시도를 안내합니다.
- 조명 바닥 전체가 책상 상판 안에 들어오면 책상 높이에 놓입니다. 책상 이동 시 조명도 함께 이동하며, 책상 밖으로 옮기면 바닥 높이로 돌아옵니다.
- 방 카메라 거리를 고려해 터치 판정 거리는 카메라의 far plane까지 확보합니다.
