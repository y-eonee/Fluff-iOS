## 원본 구간과 반복 연결

- `sourcePose(at:)`는 원본 14초/5초 구간을 끝 자세까지 그대로 샘플링한다.
- 원본 마지막 자세와 첫 자세가 같지 않으므로 지정 구간 **뒤에** 1/3초 복귀 구간을 둔다. 원본 안의 동작을 빠르게 재생하거나 종료 자세를 중립으로 바꾸지 않는다.
- 앱의 전체 반복 길이는 아침체조 14⅓초, 댄스댄스 5⅓초다. 복귀 구간은 원본에 있는 동작이 아니다.
- 원본의 회전 시점은 그대로이며 복귀 회전만 최단 방향을 사용한다.

## 캐릭터에 연결

- 같은 시간 데이터가 곰·고양이·토끼·사진 얼굴 프리셋에 적용된다.
- 내 인형의 춤 선택/만지기 미리보기도 프리셋에서는 `PresetDollView`로 같은 3D 모션을 재생한다. 이전의 완성 사진 전체 흔들기는 누끼 사진에만 남긴다. 이 수정으로 미리보기에서도 손 유지·팔 벌림·허리 숙임이 서로 구분된다.
- 동작 중에도 원래 메시, 재질, 부위별 크기는 유지한다.
- 어깨와 발 윗부분의 연결점을 실제 몸통 속에 고정한다. 얼굴 경계로 어깨를 옮기던 보정은 팔다리 분리의 원인이어서 제거했다.
- 입 근처 손짓은 얼굴 방향으로 어깨 관절을 회전시킨다. 짧은 팔이 닿지 못하는 목표 때문에 어깨를 이동하거나 팔을 늘리지 않는다. 손은 각 인형의 실제 팔 길이 안에서 움직인다.
- 누끼 인형은 분리된 팔·다리가 없으므로 전신 리듬·숙임·방향 전환만 적용된다.
- 저장 배치/충돌 최상위 객체는 유지하고 시각적 자식만 이동한다. 종료·전환 시 원래 자세를 복원한다. ‘동작 줄이기’에서는 재생하지 않는다.

## 구현과 확인

- `MorningExerciseSequence.swift`: 체조 키프레임, 공통 자세/보간/원본 이후 복귀.
- `DanceDanceSequence.swift`: 별도의 댄스 키프레임.
- `MorningExerciseMotion.swift`: 실제 부위에 연결, 허리 축 숙임, 손 목표 위치, 30fps 재생.
- `MotionReviewExporter.swift`: Debug 전용. 같은 production tracks를 가구 없는 정면에서 세 캐릭터로 렌더링하며 영상 상단에 원본 시각을 표시한다. 앱 데이터는 수정하지 않는다.

```sh
swiftc -D DEBUG -module-cache-path /tmp/malrang-exercise-module-cache Malrang/Models/MorningExerciseSequence.swift Malrang/Models/DanceDanceSequence.swift Malrang/Features/Room/MorningExerciseMotion.swift scripts/check_morning_exercise.swift -o /tmp/malrang-check-exercise
/tmp/malrang-check-exercise
```

검증 범위: 손 유지/교대, 늦은 방향 전환, 원본 종료 자세 보존, 옆 디딤, 숙임 중 발 고정, 세 가지 편집 비율, 네 클립 전체 프레임의 어깨/골반 연결점 고정 및 몸통 내부 겹침, 반복 연결, 모션 전환/복원, 동작 줄이기, 누끼/AR 대응. 타이밍/구조 테스트는 원본과의 시각적 동일성을 증명하는 테스트가 아니다.

시각 검토 실행 인자: `--export-motion-review`. 결과는 앱 Documents/MotionReview에 PNG와 MP4로 저장한다. 홈에서 확인하려면 `--design-preview=home-ui --morning-exercise-preview` 또는 `--dance-dance-preview`. `--morning-exercise-time=8` / `--dance-dance-time=2`로 정지 자세를 확인할 수 있다.

검토용 최종 영상: `artifacts/motion-review/morning-exercise.mp4` (14⅓초), `artifacts/motion-review/dance-dance.mp4` (5⅓초). H.264 720×480, 15fps. 앱 자체 모션 샘플링은 30fps. 42초 숙임 및 2초 입 근처 손짓의 실제 렌더링을 확인하고 어깨 높이·발 간격·손 위치를 재보정했다.

## 팔다리 연결 수정 (2026-11-24)

사용자가 네 동작 모두 팔다리가 분리돼 보인다고 지적해 공통 재생부를 수정했다. 원본 키프레임과 구간/박자는 유지했다.

- 어깨를 머리 가장자리로 평행 이동하던 보정, 손을 얼굴 목표점까지 평행 이동하던 보정, 발을 몸과 독립적으로 옮기던 보정을 제거했다.
- 실제 몸통(`body.fur`)의 부피 안에 어깨/발 윗부분 연결점을 잡는다. 매 프레임 회전 이후 이 점이 같은 몸통 좌표에 남도록 위치를 계산한다.
- 허리 씰룩임과 숙임에서 어깨·골반이 몸통을 따라간다. 발 디딤은 연결된 골반을 축으로 가동 범위 내에서 회전한다.
- 짧은 봉제 팔다리로 닿지 않는 목표는 관절 각도로 제한한다. 메시·재질·개별 부위 크기는 변경하지 않는다.
- 검사: 세 가지 편집 체형 × 네 클립 × 모든 샘플에서 연결점이 몸통 내부에 있고 좌표가 고정되는지 확인한다. 예전 ‘손이 목표점에 무조건 닿아야 한다’ 검사는 분리 동작을 허용하므로 연결 유지 검사로 교체했다.

연결 수정 검증 완료: iOS 빌드와 모든 연결점/복원 검사가 통과했다. 실제 고양이·곰·토끼 렌더링에서 체조 42초 숙임, 댄스 2초 손 올리기, 씰룩 16.8초 큰 기울임, 탭 0.1초 들기/0.5초 바깥 디딤의 연결을 확인했다. 최신 결과는 `artifacts/motion-attached/`에 있으며 이전 `motion-review/` 영상과 구분한다. `all-four.mp4`는 네 모션 순서대로 연결한 25.1초 영상이다. 원본 지정 구간과 기존 반복 연결 길이는 변하지 않았다.
